# Эмулятор командной строки UNIX

## 1. Общее описание
Данный проект представляет собой эмулятор командной строки, имитирующий работу в UNIX-подобной ОС. Эмулятор оснащен графическим интерфейсом (GUI) и работает с виртуальной файловой системой (VFS), которая загружается из реальной папки на диске пользователя в оперативную память. Все последующие модификации файлов происходят исключительно в памяти программы.

## 2. Описание всех функций и настроек
### Поддерживаемые команды:
* `ls` — выводит список файлов и папок в текущей директории виртуальной файловой системы.
* `cd <путь>` — осуществляет навигацию по директориям (включая возврат назад `cd ..`).
* `whoami` — выводит имя текущего пользователя операционной системы.
* `wc <файл>` — подсчитывает и выводит количество строк, слов и символов в указанном файле.
* `uniq <файл>` — выводит содержимое файла, удаляя идущие подряд одинаковые строки.
* `cp <исходный_файл> <новый_файл>` — копирует указанный файл внутри виртуальной файловой системы.
* `exit` — завершает работу эмулятора и закрывает окно.

### Настройки (файл config.toml):
Конфигурация задается в формате TOML и может быть переопределена аргументами командной строки при запуске:
* `vfs_path` — путь к реальной папке на диске, которая послужит основой для виртуальной файловой системы (например, `"my_vfs"`).
* `script_path` — путь к файлу со стартовым скриптом (например, `"startup.txt"`). Скрипт содержит список команд, которые эмулятор выполнит автоматически при запуске.

## 3. Описание команд для сборки проекта и запуска тестов
Проект написан на языке Python с использованием стандартной библиотеки, поэтому предварительная сборка (компиляция) не требуется.

**Запуск проекта:**
Для запуска в ОС Windows достаточно дважды кликнуть по файлу `run.bat` (внутри которого прописана команда `py src/main.py`). Также программу можно запустить вручную из терминала:
`python src/main.py` или `py src/main.py`

**Запуск тестов:**
Тесты располагаются в папке `tests`. Запуск всех тестов осуществляется стандартным модулем unittest из корневой директории проекта командой:
`python -m unittest discover tests`

## 4. Примеры использования
Ниже приведен пример интерактивного сеанса работы с эмулятором:

> whoami
Asus

> ls
hello.txt.txt

> cp hello.txt.txt copy.txt
> ls
hello.txt.txt copy.txt

> wc hello.txt.txt
1 1 6 hello.txt.txt

> exit
